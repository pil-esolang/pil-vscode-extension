# Changelog

## 0.2.0

- Update language support to PIL 0.9.0 and its completed documentation.
- Refresh all 273 runtime built-ins and add 38 constant-evaluator function previews.
- Support hash comments, semicolon statements, multiline syntax and `local` declarations.
- Add chained constants/globals, enumerations, enum arrays and parenthesized structures throughout completion, highlighting and navigation.
- Fix function highlighting inside comments.
- Link every built-in description to its official documentation header.

## 0.1.0

- Add full PIL highlighting and a 291-entry built-in catalog.
- Add scope-aware completions, parameter hints and hover documentation.
- Add include-aware definitions, references, Outline and workspace symbols.
- Add struct-field suggestions, semantic highlighting and offline built-in references.
