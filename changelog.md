# Changelog

## 1.1.0
- Added signed number literals, made trailing commas a strict error for locals, globals and function calls and fixed some error diagnostics.

## 1.0.0
- Initial version made for PIL interpreter 1.0.0.
- Includes descriptions and support for all 268 built-ins and 38 evaluator functions.
- Various checks and diagnostics for missing semicolons, commas, using unknown variables, wrong argument counts and other common mistakes.
- Support for all PIL's structures and operators.
- Autocomplete, snippets and hover info.
